Meltingplot operator panel image mp-hmi-pi5, version @VERSION@
Software licences and source code
==============================================================================

This file describes the licence terms of the software on the operator panel
of this printer and where its source code is. It is part of the image and is
replaced with every update, so it describes the software that is actually
installed. The panel shows it at /licenses/, together with the licence file
of every installed package. The printer's own computer, behind the panel,
has its notice at 0:/sys/LICENSES.txt in Duet Web Control.


1. What the software is and who licensed it
------------------------------------------------------------------------------

Operating system
  Debian 13 (trixie) with the additions of Raspberry Pi OS, including the
  Raspberry Pi Linux kernel (GPL-2.0). Every Debian package carries its own
  licence file, shown at /licenses/packages/<package>; most are GPL, LGPL,
  BSD or MIT.

Operator panel
  labwc, the compositor of the screen: GPL-2.0.
  Chromium, the browser that shows the printer's interface: BSD-3-Clause,
    with third-party parts under their own terms, among them LGPL, MPL and
    the Microsoft Public License (Ms-PL), all listed at
    /licenses/packages/chromium.
  squeekboard, the on-screen keyboard: GPL-3.0-or-later.
  wf-panel-pi, the panel at the top edge: MIT; its network applet
    (wfplug-netman) and connection editor (lp-connection-editor):
    GPL-2.0-or-later.
  lisgd, the swipe that brings the panel down: MIT.
  haproxy, which passes the printer's interface on: GPL-2.0-or-later.
  motion, the camera stream: GPL-2.0-or-later. libcamera: LGPL-2.1-or-later.
  NetworkManager: GPL-2.0-or-later. chrony, the time server of the printer
    network: GPL-2.0. polkit: LGPL-2.0-or-later.

Meltingplot software
  The image definition and build, based on rpi-image-gen by Raspberry Pi Ltd:
  BSD-3-Clause.
  https://github.com/Meltingplot/rpi-image-gen
  The interface the panel shows comes from the printer's computer and is
  described in its notice.

Raspberry Pi Connect (Raspberry Pi Ltd)
  rpi-connect: distributed in binary form only. Raspberry Pi licenses the
  binaries under BSD-3-Clause terms and does not publish their source; the
  bundled Go modules are open source under MIT, BSD and Apache-2.0, each
  listed at /licenses/packages/rpi-connect.
  wayvnc, which shares the screen: ISC.
  rpi-connect-ota: Apache-2.0, from rpi-sb-provisioner.

Firmware
  The boot firmware (raspi-firmware) and the bootloader of the Raspberry Pi 5
  (rpi-eeprom) are not open source. They may be redistributed in binary form
  for use on Raspberry Pi devices under the terms in section 4.
  The firmware of the wifi chip (package firmware-brcm80211, files under
  /usr/lib/firmware/brcm and /usr/lib/firmware/cypress) is not open source
  either. It is distributed complete and unmodified, for use with that chip
  only, under the licence agreements of Broadcom and Cypress, see section 4.


2. Source code
------------------------------------------------------------------------------

The corresponding source code of this image version is public for every
component except those named above as binary only, Raspberry Pi Connect and
the firmware, which carry no source obligation:

  Image definition and build
    https://github.com/Meltingplot/rpi-image-gen
    Release tag hmi-pi5/v@VERSION@. The file release.json in that release
    names the exact commit of the image definition that this image was built
    from, and the checksums of every delivered file.

  Debian packages
    https://deb.debian.org/debian (source packages, by the version named in
    the software bill of materials of the release, and /licenses/index.json)
    https://archive.raspberrypi.com/debian and
    https://github.com/raspberrypi for the Raspberry Pi additions and kernel

The software bill of materials (SBOM) of the release lists every component
with its exact version.

Written offer
  For three years from the delivery of this machine, Meltingplot will provide
  the complete corresponding source code of any component licensed under the
  GPL or LGPL on a data carrier, for no more than the cost of doing so.
  Contact: https://meltingplot.net


3. Installing modified software
------------------------------------------------------------------------------

This computer starts only images signed by Meltingplot. To run a modified
version of the software, build the image from the sources in section 2 and
write it to a Raspberry Pi 5 that has not been provisioned for secure boot,
then fit that Raspberry Pi in place of this one. The printer works with it.

Whoever does so is responsible for the modified machine: under the Machinery
Regulation (EU) 2023/1230, replacing the control software of a machine makes
the person who does it the manufacturer of the resulting machine.
